# Подбор автозапчастей (Favorit Parts)

Клиентское приложение для подбора автозапчастей и аналогов через внешний сервис «Проценка»: пользователь вводит артикул, выбирает производителя и получает предложения поставщика.

## Язык

**Артикул**:
Номер детали, который однозначно определяет её внутри одного производителя, но не между производителями.
_Avoid_: Номер, part number, OEM-номер

**Производитель**:
Бренд, выпускающий деталь с данным артикулом.
_Avoid_: Марка, бренд, вендор

**Аналог**:
Деталь другого производителя, которая заменяет искомую деталь.
_Avoid_: Замена, кросс, дубль

**Предложение**:
Наличие конкретной детали на конкретном складе, с собственной ценой и остатком.
_Avoid_: Оффер, позиция склада

**Деталь**:
Конкретная запчасть — сочетание артикула и производителя, с названием и совокупностью предложений.
_Avoid_: Товар, позиция, продукт
